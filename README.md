# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 核对规则

- 可用枚数以字模库为唯一准绳：落字、换字、清空都按它核对，不够会拦下本次操作并写明还差几枚。
- 字模卡上的 −/＋ 可直接增减库存；库存变动后，版面与每张草稿的占用都会重算，缺口（还差几枚）标红显示。
- 草稿会记下占用快照，即使字模后来被删掉，也能标出「需几枚/库几枚」的缺口。
- 导出预览按重算后的版面绘制：缺口格画成红色虚线框，图底部注明各字还差几枚。

## 多窗口并行保存

- 两个窗口同时保存时，字模与草稿按 id 合并，两边已保存的草稿都保留，不会被后保存的整份盖掉。
- 检测到冲突会弹出提示条，冲突处理完之前草稿不做数量裁剪；核对并删除多余草稿后点「已处理」即可。
